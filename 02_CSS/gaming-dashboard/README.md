# GameHub Gaming Dashboard

A modern gaming dashboard UI built as an HTML and CSS practice project.

This project was created to practice CSS layout techniques, positioning, alignment and reusable styling through a gaming dashboard interface.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 CSS Concepts Practiced

- `margin: auto`
- `position: relative`
- `position: absolute`
- `position: fixed`
- `align-self`
- CSS utility classes
- Reusable CSS styling

## 🔗 Live Demo

View Live Demo: https://gamehub-dashboard.netlify.app/

## 💡 What I Learned

This project helped me practice Reusable CSS styling and positioning techniques by building a modern gaming dashboard interface.

I learned how Flexbox, margin auto, positioning properties, align-self and reusable CSS utility classes can work together to create and organize a structured user interface.
