# Unit Converter

A simple Metric/Imperial Unit Converter built as a JavaScript practice project.

This project was created to practice JavaScript fundamentals, DOM manipulation and event handling through an interactive unit conversion tool.

## 🚀 Features

- Converts length between meters and feet
- Converts volume between liters and gallons
- Converts mass between kilograms and pounds
- Displays conversions up to 3 decimal places
- Updates all conversion values at once
- Reset button to clear the input and reset conversions
- Simple and clean UI inspired by the Scrimba project design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 JavaScript Concepts Practiced

- constants
- Objects
- Getting input values
- `addEventListener()`
- `Number()`
- `toFixed()`
- Object property access

## ⚙️ How It Works

### Input:
Takes a numeric value from the input field and converts it from a string to a number using `Number()`.

### Conversion:
Calculates length, volume and mass conversions using predefined conversion formulas.

### Conversion Object:
The conversion results are returned from a function as an object and accessed through its properties.

### Display:
Updates all conversion values on the page and displays the results with 3 decimal places.

### Reset:
Clears the input field, resets the value to zero and updates the displayed conversions.
