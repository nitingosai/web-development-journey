# StreamFlix — Feedback Experience

A Netflix-inspired feedback collection interface built with HTML, CSS and JavaScript.

## Features
- Name, rating and feedback form
- Inline form validation
- Interactive 1–5 star rating
- Dynamically created feedback cards
- Newest feedback appears first
- Live feedback count
- Auto-hiding success message
- Temporarily disabled submit button
- Responsive layout

## Concepts Practiced
- Forms and `FormData`
- `FormData.get()`
- `event.preventDefault()`
- DOM manipulation and `document.createElement()`
- `element.style`
- `classList.add()`, `classList.remove()` and `classList.toggle()`
- `setTimeout()` and `clearTimeout()`
- `disabled` attribute
- Event listeners

## Run Locally
1. Extract the ZIP file.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build tools are required.

## Note
This is an independent frontend practice project inspired by the visual style of streaming platforms. It is not affiliated with or endorsed by Netflix. Feedback is only displayed during the current page session and is not sent to a server.
