# Basketball Scoreboard

A simple Basketball Scoreboard built as a JavaScript practice project.

This project was created to practice JavaScript fundamentals and basic DOM manipulation by building an interactive basketball scoreboard.

## 🚀 Features

- Add 1, 2, or 3 points to the Tigers
- Add 1, 2, or 3 points to the Hawks
- Track fouls for both teams
- Track timeouts for both teams
- Display which team has possession
- Change the current quarter
- Reset scores, fouls, and possession when moving to the next quarter
- Basketball-themed scoreboard UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

### ⚙️ How It Works

Score:
Adds 1, 2, or 3 points to the selected team's score.

Fouls:
Increases the foul count for the selected team.

Timeouts:
Increases the timeout count for the selected team.

Possession:
Displays which team currently has possession.

Next Quarter:
Moves to the next quarter and resets the scores, fouls, and possession for the new quarter.
