# Wildlife Adventure Quiz

A simple Wildlife Adventure Quiz built as a JavaScript practice project.

This project was created to practice JavaScript fundamentals and basic DOM manipulation through an interactive quiz game.

## 🚀 Features

- 20 wildlife questions
- 5 random questions per quiz
- 4 multiple-choice options for each question
- Prevents duplicate questions in the same quiz
- Tracks the player's score
- Highlights correct and incorrect answers
- Prevents multiple answers for the same question
- Displays a final score
- Displays a personalized message based on the score
- Simple nature-inspired UI

## ⚙️ How It Works

### Question Selection:
Selects 5 random questions from a set of 20 questions while preventing duplicate questions in the same quiz.

### Answer Selection:
Displays four options for each question. Once an answer is selected, the correct answer is highlighted and the score is updated if the selected answer is correct.

### Quiz Progress:
The player answers 5 questions before the quiz is completed.

### Score:
The final score is saved and displayed on the score page along with a message based on the player's performance.
