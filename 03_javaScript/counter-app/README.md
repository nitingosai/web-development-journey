# Counter App

A simple Counter App built as my first JavaScript practice project.

This project was created to practice JavaScript fundamentals and basic DOM manipulation.

## 🚀 Features

- Increment the current count
- Save the current count
- Display the last saved count
- Display the save time
- Reset the current count after saving
- Simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

- Script tag

- Functions
- Basic DOM manipulation
- Updating HTML content with JavaScript
- Working with "Date"

### ⚙️ How It Works

Increment:
Increases the current count by 1.

Save:
Saves the current count, displays it as the last entry, shows the save time, and resets the current count to 0.
