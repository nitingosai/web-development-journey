# Password Generator

A simple Password Generator built as a JavaScript practice project.

This project was created to practice JavaScript fundamentals and basic DOM manipulation.

## 🚀 Features

- Generate two random passwords
- Set password length
- Generate passwords with letters, numbers and symbols
- Display generated passwords
- Validate password length
- Display instructions for invalid input
- Simple dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📚 JavaScript Concepts Practiced

- Arrays
- Objects
- Functions and return statements
- if / else if / else
- Comparison and logical operators
- for loops
- Math object
- Getting input values
- Updating HTML content

## ⚙️ How It Works

### Password Length:
Takes the desired password length from the number input.

### Generate Passwords:
Generates two random passwords using letters, numbers and symbols.

### Validation:
- Empty input → Ask the user to enter a password length
- 5–15 → Generate passwords
- Invalid length → Display an error message
