# Black Jack Game

A simple Black Jack Game built as a JavaScript practice project.

This project was created to practice JavaScript fundamentals and basic DOM manipulation.

## 🚀 Features

- Start a new game
- Generate random cards
- Display cards and total
- Detect Black Jack at 21
- Detect when the player goes over 21
- Display game status
- Simple casino-inspired UI

- HTML5
- CSS3
- JavaScript

## ⚙️ How It Works

### Start Game:
Generates two random cards and calculates their total.

### Add New Card:
Generates a new random card and updates the total.

### Game Rules:
- Below 21 → Continue the game
- Exactly 21 → Black Jack
- Above 21 → Game Over
